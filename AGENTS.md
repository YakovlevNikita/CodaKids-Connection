# CodaKids Connection — Справка для агентов

## Обзор проекта

**CodaKids Connection** — клиентское одностраничное веб-приложение для записи школ на мастерклассы, проводимые в июне 2026 года. Приложение реализовано как статический HTML-файл с встроенными стилями и скриптами. Не требует сервера, сборки или зависимостей — достаточно открыть `index.html` в браузере.

Основные возможности:
- Просмотр календаря доступных дат (июнь 2026).
- Авторизация школ и администратора.
- Запись на мастерклассы с ограничением по слотам.
- Личный кабинет с просмотром и отменой записей.
- Админ-панель с экспортом/импортом данных в JSON и управлением записями.

Язык интерфейса, документации и комментариев в коде — **русский**.

---

## Технологический стек

- **HTML5** — разметка.
- **CSS3** — кастомные стили (без фреймворков), адаптивная вёрстка через `@media`.
- **Vanilla JavaScript (ES6)** — вся логика на чистом JS, без библиотек и фреймворков.
- **localStorage** — персистентное хранение сессии пользователя и записей на мастерклассы.

Нет package-менеджера, нет сборщиков, нет транспиляторов, нет конфигурационных файлов сборки (например, `package.json`, `vite.config.js` и т.п.).

### Примечания по структуре

- Весь код приложения сосредоточен в одном файле `index.html`:
  - `<style>` (строки 7–687) — все CSS-правила, включая стили интро-экрана, DOS-стиля авторизации и адаптив.
  - `<script>` (строки 859–1648) — вся логика на JavaScript.
- Данные (пользователи, мастерклассы, расписание) объявлены прямо в скрипте как константы (`USERS`, `WORKSHOPS`, `PHASE1_DATES` и т.д.).

## Запуск и развёртывание

### Локальный запуск

Поскольку это статический HTML-файл, достаточно:

```bash
# Открыть файл в браузере напрямую
start index.html        # Windows
open index.html         # macOS
xdg-open index.html     # Linux
```

Или поднять локальный сервер (опционально):

```bash
# Python 3
python -m http.server 8000

# Node.js (если установлен)
npx serve .
```

### Деплой

Приложение можно развернуть на любом хостинге статических сайтов:
- GitHub Pages
- Netlify / Vercel
- Любой веб-сервер (nginx, Apache)

В `plan.md` упоминается GitHub Pages как предпочтительный вариант деплоя.

## Организация кода

### Модули внутри `index.html`

В `<script>` логика разделена комментариями на секции:

| Секция | Назначение |
|--------|-----------|
| `DATA` | Константы: `USERS`, `WORKSHOPS`, `ALL_WORKSHOPS`, `PHASE1_DATES`, `PHASE2_DATES`, слоты времени, `MONTH_NAMES`, `DAY_NAMES`. |
| `STATE` | Глобальные переменные `currentUser` и `bookings`. |
| `CODE TYPING INTRO` | Анимация печати кода в редакторе на интро-экране (`startCodeTyping`, `highlightEditorLine`, вспомогательные переменные). |
| `INIT` | `init()`, `loadState()`, `saveState()` — инициализация, работа с `localStorage`, обработчики клавиатуры/кликов для интро. |
| `AUTH` | Две точки входа: авторизация через интро (`doIntroLogin`, `showAuthSlide`, `hideAuthSlide`, `completeIntro`, `dismissIntro`) и DOS-модалку в шапке (`toggleAuth`, `doLogin`, `doLogout`, `updateUI`). |
| `CALENDAR` | Рендеринг календаря на июнь 2026, определение доступности дат и слотов (`renderCalendar`, `getBookingsForDay`, `hasFreeSlots`, `getWorkshopStatus`, `getSpotsLeft`, `isSchoolBooked`, `isSchoolBookedWorkshop`). |
| `BOOKING MODAL` | Модальное окно выбора слота и мастеркласса, запись и отмена (`openBookingModal`, `closeBookingModal`, `bookWorkshop`, `cancelBooking`). |
| `MY BOOKINGS` | Отображение записей текущего пользователя (`renderMyBookings`). |
| `WORKSHOPS SECTION` | Карточки с описанием 4 мастерклассов (`renderWorkshops`). |
| `TEACHERS SECTION` | Карточки преподавателей (`renderTeachers`). |
| `ADMIN` | Таблица всех записей, экспорт/импорт JSON, очистка данных (`renderAdminTable`, `adminCancelBooking`, `exportData`, `importData`, `clearAllData`). |
| `UTILS` | Вспомогательные функции (`scrollToSection`, закрытие модалок по клику на оверлей, обработка Enter в полях пароля). |

### Роли пользователей

- `school` — 19 школ (`школа1` … `школа19`), могут записываться на мастерклассы.
- `admin` — администратор (`admin` / `admin123`), имеет доступ к админ-панели, но не может записываться.

### Правила записи

- Одна школа может быть записана только на **один мастеркласс в одном слоте**.
- **Студийные** мастерклассы (`studio`) имеют лимит до 12 участников на слот.
- **Выездные** мастерклассы (`outbound`) имеют практически неограниченное число мест (`maxSlots: 999`).

### Расписание (июнь 2026)

- **Фаза 1** (4, 5, 8–12 июня, рабочие дни): один слот `15:30–17:00`.
- **Фаза 2** (15–19 июня, рабочая неделя): три слота `10:00–11:30`, `12:00–13:30`, `14:00–15:30`.

## Стиль кода

- Отступы: 4 пробела.
- Именование переменных и функций: `camelCase`.
- CSS-классы: `kebab-case`.
- Константы данных: `UPPER_SNAKE_CASE` (`USERS`, `WORKSHOPS`).
- Глобальные функции объявлены как `function name() { ... }`.
- DOM-элементы создаются через `document.createElement` (для сложных структур), но для простых карточек допускается `innerHTML`.
- Состояние (`currentUser`, `bookings`) хранится в глобальных переменных модуля `<script>`.

## Безопасность

> ⚠️ **Важно**: текущая реализация — исключительно клиентская демонстрация. Не используйте эту версию как образец для систем с реальными данными.

- Учётные данные хранятся **в открытом виде** прямо в JS-коде (`USERS`).
- `localStorage` доступен любому скрипту на странице.
- Нет серверной валидации — все проверки выполняются на клиенте и могут быть обойдены.
- В `plan.md` запланирована серверная версия на Node.js/Express (этап 11) для устранения этих ограничений.
